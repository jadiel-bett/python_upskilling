# Python Upskilling Journey

This repository is dedicated to tracking my progress as I level up my Python skills. It serves as a central hub for capturing challenge questions, solutions, and notes from various learning platforms and projects.

## 🎯 Objectives

- Solve algorithmic challenges.
- Implement design patterns in Python.
- Explore new libraries and frameworks.
- Document learning milestones.

## 📁 Structure

The repository is organized by platform and category to keep solutions clean and accessible:

```text
python_upskilling/
├── HackerRank/
│   ├── Easy/
│   │   └── challenge_name/
│   │       ├── solution.py
│   │       └── README.md (Problem description & approach)
│   ├── Medium/
│   ├── Hard/
│   └── ...
├── LeetCode/
│   └── ...
└── README.md
```

Each challenge folder contains the implementation and a short note on the logic used.
